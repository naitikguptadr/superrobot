# SuperRobot UI visual QA

Pass only if all are true:

1. First viewport is brand-first (SuperRobot + DataRobot signal), not generic chat chrome.
2. Removing the word "SuperRobot" still does not look like stock Pi.
3. Palette uses theme tokens from `shell/theme/superrobot.theme.json` (deep navy + teal accent), not purple glow or default gray terminal.
4. Typography is expressive (theme stack), not Inter/Roboto/system default alone.
5. At least two intentional motions exist in the interactive path (splash, stage pulse, or deploy ignite).
6. Capability chips (Gateway / Workload / Memory / Agent App) are visible after setup.
7. No card soup / pill cluster / emoji decoration.
